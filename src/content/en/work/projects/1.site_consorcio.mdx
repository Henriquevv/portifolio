## Letter of Credit Analyzer and Optimizer (Consortia)

**Letter of Credit Analyzer and Optimizer** is a complete platform for financial analysis, web scraping and combinatorial optimization of consortiums.  
It brings together *Data Engineering*, *Operational Research*, *Clean Architecture* and *Full Stack Development* techniques to deliver a system capable of analyzing thousands of letters in a few milliseconds.

The solution combines:

- Robust Web Scraping with WAF bypass (Cloudflare)  
- Advanced optimization algorithms (*Branch & Bound*, Pareto Dominance, Fail-Fast)  
- High performance API with FastAPI  
- Smart caching with Redis  
- Persistence with PostgreSQL  
- Frontend in Vanilla JS with Dark Mode and simulated SPA  

---


## System Objective

The project solves a classic problem in the consortium market:  
**“How to put together the best combination of cards to reach a target credit with the lowest total cost?”**

While most tools just do simple comparison, this system:

- Consolidates data from multiple sources  
- Uses real mathematical optimization  
- Allows credit tolerance  
- Performs multi-restriction analysis (entry, installment, administrator, etc.)

## Engineering Structure and Algorithms

### 1. Branch & Bound

The optimization engine implements:

- **Lookahead Pruning**  
  Uses pre-calculated tables to decide whether a branch will be infeasible before testing it.  

- **Fail-Fast Ordering**  
  Cards are sorted by total cost, reducing search time exponentially.

---

### 2. Search Space Reduction (Pareto Dominance)

Before starting the algorithm, the system removes:

- Strictly worse cards  
- Masked duplicates  
- Inconsistent entries  

This drastically reduces the number of possible combinations.

---

### 3. Parallel Processing

Each administrator is evaluated in parallel using `ThreadPoolExecutor`, allowing:

- Much higher speed
- Lower latency
- Horizontal scalability in the cloud
